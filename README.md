# Lista de Tarefas

Aplicativo de lista de tarefas feito com **HTML, CSS e JavaScript puro**, sem frameworks. Projeto criado para praticar os fundamentos do desenvolvimento web.

🔗 **Acesse o app:** https://hectorhenriqueborges.github.io/lista-de-tarefas/

## Funcionalidades

- Adicionar, editar (duplo clique) e excluir tarefas
- Marcar tarefas como concluídas
- Filtros: todas, pendentes e concluídas
- Contador de tarefas pendentes
- Prioridade (alta, média e baixa) com cores
- Data limite, com destaque para tarefas atrasadas
- Botão para limpar tarefas concluídas
- Modo escuro
- Os dados ficam salvos no navegador (localStorage)

## Tecnologias

- HTML5
- CSS3 (flexbox e variáveis CSS)
- JavaScript (manipulação do DOM e localStorage)
- Git, GitHub e GitHub Pages

## Como rodar localmente

1. Baixe ou clone este repositório
2. Abra a pasta no VS Code
3. Abra o `index.html` com a extensão Live Server (ou direto no navegador)
